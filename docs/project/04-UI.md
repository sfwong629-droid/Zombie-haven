# Zombie Haven: UI

Owner, 16 Nov 2026: **"The UI still needs a lot of work."** This page is the UI's direction, rules and problem list. All UI work happens in its own chat. Open questions for the owner are tracked in `05-NOW.md` under "UI chat".

## A. Direction (decided)
- **Glass · Sticker icons** (picked 5 Nov; full spec and the rejected styles in `claude/zombie-haven-ui-directions.md`).
  - Dark frosted panels, 1px light edge, radius 18; white text, muted #C9D1D9.
  - Accent lime #C6FF4D for Build / go; danger coral #FF7A59. Font Manrope.
  - Full-colour sticker icons with a thick white edge.
  - **Rim light** (owner, 18 Nov): a bright glass rim fading down from each menu's top edge, a soft blue glow at the top left; cards, buttons and tabs lit from above like raised glass. Tabs are separate buttons.
- **Phone shape** always (no desktop layout). HUD scales with the phone column; buttons never under 44 px.
- **Layout:** resource pill top centre; mission card top left; clock and renown top right; round side buttons on the right; floating bottom tab bar with the big Build button.

## B. Rules (decided)
- Menus (People, Build, Town, survivor details) pause the game. Map pop-ups, news and radio don't.
- **Nothing floats over an open menu** (owner, 16 Nov). For every menu:
  - the radio button is hidden while the menu is open;
  - the alert button sits *under* the menu: the menu covers it completely and it comes back when the menu closes; it is never part of the menu;
  - the "Paused" pill sits centred on the menu's top edge, not on the mission card.
- Messages each have one home:
  - critical: red strip under the top bar;
  - news: ONE pill;
  - DJ: radio card on the tab bar;
  - tap feedback: a short line above the radio.
- Have / need numbers on every cost (red short, green ready).
- **A share of a whole is written as a percentage** ("95%"), never "95/100" (owner, 16 Nov). Real counts (have / need, mission progress) stay as counts. **Health is never a percentage** (owner, 18 Nov, W108): survivors' HP, building health and wall HP stay as counts ("49/101").
- Icons fill 80–90% of their button; no empty boxes.
- Popup buttons are green only when recommended.
- **Lime is only for Build / go / recommended** (owner, 18 Nov, W109). A selected tab or option is plain white, not lime.
- Panels keep full contrast at night.
- Text: facts first, joke last.

## D. How UI work is done
1. Pick one screen or one problem.
2. Claude shows a before / after picture first; the owner approves.
3. Build it, run the layout check (six phone sizes: no overlap, nothing off-screen, taps 44 px+).
4. ChatGPT screenshot review of the changed screens.
5. Publish; update this page.
